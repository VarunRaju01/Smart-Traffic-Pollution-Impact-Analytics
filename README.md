# Smart Traffic & Pollution Impact Analytics

## Project Overview

This project analyzes traffic congestion and pollution trends using data analytics techniques. The project studies traffic patterns, weather impact, pollutant behavior, and environmental trends using visualization and statistical analysis.

---

## Objectives

- Analyze traffic congestion patterns
- Study pollution trends
- Understand weather impact on traffic
- Identify high pollution conditions
- Generate insights for smart city planning

---

## Datasets Used

### Traffic Dataset
Contains:
- Traffic volume
- Vehicle counts
- Vehicle speed
- Weather conditions
- Accident reports

### Pollution Dataset
Contains:
- PM2.5
- PM10
- NO2
- SO2
- CO
- O3

## Key Insights

- Peak traffic occurs during office hours.
- Weather conditions affect traffic flow.
- PM2.5 and PM10 are dominant pollutants.
- Heavy traffic contributes to pollution levels.
